Model Librarian · Workflow tabComfyUI
model
MODEL

Missing models, found and fetched

Open anyone's workflow and Model Librarian lists every model it can't find, with a source for each. Downloads land in the right folder, checked against their SHA256, and pick up where they stopped.

  • Looks in the workflow's own links, ComfyUI's templates, HuggingFace, CivitAI and CivArchive.
  • All saved workflows checked at once, and moved models repointed.
  • Share a workflow with every model's download link built in.
CivitAI · Model Librarian for ChromeChrome and Edge
model
MODEL

One click on CivitAI

The browser extension puts a panel on every CivitAI model page. It picks the file that fits your GPU and VRAM, adds the text encoder and VAE it needs, and hands the download to Model Librarian.

  • Have and Update badges on CivitAI's model cards.
  • Every model a CivitAI image used, saved as a recipe in one click.
  • ComfyUI can be closed: clicks wait and start when it's back.

Not on the Chrome Web Store or Edge Add-ons yet. Until then it installs with Load unpacked (see Install).

Model Librarian · LibraryComfyUI
model
LIBRARY

Sorted by base model

Your models in one gallery with CivitAI previews, trigger words and base-model badges. The organizer files them into Illustrious, Pony, Flux and the rest, and repoints your saved workflows to match.

  • Update alerts for newer CivitAI versions, compared before you download.
  • Models taken down from CivitAI are flagged, since yours may be the last copy.
  • Duplicates under any name, and downloads that never finished.
Model Librarian · StorageComfyUI
library
LIBRARY

The SSD keeps what you use

Models you haven't touched in a while move to an archive drive and keep working under the same names. The moment a workflow needs one again, it comes back to the SSD.

  • Set a free-space goal; the least recently used models are suggested first.
  • Every ComfyUI on the same models folder shares one library.

Any image becomes a recipe

Drop in an image or a ComfyUI video, or paste a CivitAI link. You get its prompt, settings, checkpoint and every LoRA with its strength, then download what you're missing and load it into the workflow.

  • Reads ComfyUI, A1111 and Forge, CivitAI, Fooocus, InvokeAI, SwarmUI and NovelAI images.
  • Save what made your own image as a recipe after a run.

Model Librarian GalleryWindows
images

Every picture remembers what made it

Model Librarian Gallery is a fast Windows app for your AI generations, photos and illustrations. It reads the prompt, settings, models and workflow saved in each file, and the Gallery Info node files new images as they're made.

  • Search with lora:, model:, character: and more; statistics on what you make with.
  • Open in ComfyUI sends any picture's workflow back to a new tab.
  • Indexes your folders where they are. Nothing is copied, and nothing leaves your PC.

Sort a big library, from anywhere

Thousands of images a week are easy to make and hard to keep up with. The Gallery helps you go through them.

Characters

With ComfyUI

Give a character its LoRA, trigger words or tags, and the Gallery finds every image it's in; anything uncertain waits in To review for a yes or no. It's the same list Model Librarian's Character Select uses in ComfyUI, kept in step both ways.

Phone and tablet

iPhone and Android

Pair a phone with a QR code and your library goes with you, over Tailscale: swipe through, pinch to zoom, rate and tag, and save any picture to the phone's photos. Add it to the home screen and it opens like an app.

Swipe

Mouse, keys or touch

Go through a day's batch one image at a time: left to delete, right to keep, up to favourite, a star to rate it or an album to file it. Your place is remembered for next time.

Install

Each part works on its own; together they hand work to each other. Start with Model Librarian in ComfyUI.

Model Librarian

ComfyUI custom nodes · v1.23
comfy node install comfyui-model-librarian
  1. Or search Model Librarian in ComfyUI-Manager.
  2. Restart ComfyUI and open Library in the toolbar.
  3. Add your CivitAI API key in Settings for CivitAI downloads.
Comfy RegistryGitHub

Model Librarian for Chrome

Chrome and Edge extension · v0.6.1
  1. Download the repository as a ZIP and unzip it.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Choose Load unpacked and pick the folder with manifest.json.

Needs Model Librarian 1.15 or newer. Store listings are on the way.

Model Librarian Gallery

Windows app · portable
  1. Download the portable ZIP from the latest release.
  2. Unzip it outside OneDrive, for example into %LOCALAPPDATA%\Programs.
  3. Start Model Librarian Gallery.exe. It isn't signed yet, so Windows SmartScreen may ask first: choose More info, then Run anyway.
